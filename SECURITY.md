# Security Policy

## Responsible Use

This project is intended for education and authorized defensive monitoring.
Only use it on files and systems that you own or have permission to inspect.

## Reporting a Vulnerability

Do not publish sensitive exploit details in a public issue. Contact the project
maintainer privately with a description, reproduction steps, impact, and a
suggested mitigation if available.

## Important Limitation

The baseline and log are ordinary local files. Store them outside the monitored
directory and protect their permissions when using the tool beyond a classroom
demonstration.
